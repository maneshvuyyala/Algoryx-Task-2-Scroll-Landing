A responsive and interactive scroll-based landing page built using React.js and Vite as part of my internship at Algoryx.

This project is focused on creating a modern landing page with smooth scrolling, scroll-based animations, responsive layouts, interactive sections, and a simple user experience.

## About the Project

The purpose of this project is to develop a practical understanding of React.js and frontend development by building a scroll-based animated landing page from scratch.

It includes multiple sections and interactive UI components designed to provide a smooth and engaging browsing experience.

## Tech Stack

- React.js
- JavaScript
- Vite
- HTML5
- CSS3
- Lucide React
- Git & GitHub

## Features

- Responsive navigation bar
- Animated hero section
- Smooth scrolling
- Scroll reveal animations
- Parallax-style section
- Animated statistics section
- Services / feature cards
- Process timeline
- Testimonials section
- Contact form with validation
- Dark / light theme
- Scroll progress indicator
- Responsive design for different screen sizes
- Interactive hover and transition effects
